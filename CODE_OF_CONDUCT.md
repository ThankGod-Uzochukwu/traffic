# Code of Conduct

This project is small and volunteer run. The expectation is simple: be respectful, and assume good faith.

## What that means in practice

- Disagree about the work, not the person. Critique code and ideas, not people.
- No harassment, insults, or personal attacks, in issues, pull requests, commits, or anywhere else tied to this project.
- Respect that contributors have different backgrounds, experience levels, and time to give. A beginner's question deserves the same patience as an expert's.

## If something goes wrong

If someone's behavior in this project's spaces makes you uncomfortable, open an issue, or if that does not feel safe, reach out to a maintainer directly. Reports will be handled privately and taken seriously.

## Enforcement

Maintainers can remove comments, close issues or pull requests, or block contributors who violate this. The goal is a project people actually want to work on, not a rulebook for its own sake.
